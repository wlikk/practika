
Инструмент для визуализации графа зависимостей пакетов NuGet.

## Этапы реализации

### Этап 1
Минимальный прототип с настройкой параметров через командную строку.

**Параметры:**
- `-p, --package` - Имя анализируемого пакета (обязательный)
- `-s, --source` - URL репозитория или путь к файлу (обязательный)  
- `-t, --test-mode` - Режим тестового репозитория (0/1)
- `-f, --filter` - Подстрока для фильтрации пакетов

**Пример:**
```bash
python stage1.py -p "Newtonsoft.Json" -s "https://api.nuget.org/v3-flatcontainer" -t 0 -f "Json"

python stage1.py -p "Test"  # ошибка: missing --source

python stage1.py -p "Test" -s "url" -t 2  # ошибка: invalid choice

### Этап 2

**Параметры:**

-s, --source - URL репозитория NuGet

**Пример:**
```bash
python stage1.py -p "Microsoft.EntityFrameworkCore"
