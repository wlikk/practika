# VFS Emulator - Документация

## Общее описание

VFS Emulator - это эмулятор виртуальной файловой системы с графическим интерфейсом, написанный на Python с использованием библиотеки tkinter. Программа предоставляет терминальный интерфейс для выполнения базовых команд файловой системы и поддержку выполнения стартовых скриптов.

### Поддерживаемые команды

- **`ls [аргументы]`** - отображает переданные аргументы (в текущей реализации)
- **`cd [путь]`** - изменяет текущую директорию (заглушка)
- **`exit`** - завершает работу приложения

## Использование

### Запуск с параметрами по умолчанию:
```
python vfs_emulator.py
```
